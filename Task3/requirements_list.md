# Требования к внешним интеграциям
## Безопасность

1. Защищенная передача данных, протокол TLS 1.2+
2. Между сервисами mTLS
3. Входящие хуки от партнера в PropDevelopment и обратно из PropDevelopment подписаны HMAC-SHA256
4. Секреты и ключи надежно хранятся в специальных хранилищах, меняются с заданной периоличностью
5. При передаче данных используются только идентификаторы
6. Идемпотентность запросов в обе стороны
6. Логирование передачи данных в обоих направлениях, без чувствительных данных
7. По 152-ФЗ - взять согласие у пользователя на передачу данных (биометрия) в сервис партнера с указанием целей и сроков хранения

## Протоколы аутентификации и авторизации

1. Аутентификация и авторизация пользователей мобильного приложения с использованием keycloak и MFA
2. Мобильное приложение отправляет запросы с JWT токеном
3. Взаимная авторизация между партнерским сервисом и PropDevelopment по OAuth2


## Взаимодействие систем

1. из PropDevelopment в Партнерское приложение:
   1. создание/удаление пропуска по биометрии
   2. создание/удаление пропуска по номеру
   3. разове открыте двери
   4. разовое открытие шлагбаума
2. Партнерское приложение -> PropDevelopment:
   1. вход
   2. въезд
   3. распознавание
   4. отказ
3. Ретраи, таймауты, ограничения:
   1. Ретрай запросов при сбое
   2. Таймауты
   3. Оповещения при длительных сбоях
   4. Лимиты на запросы в единицу времени
